# Task 7：实施里程碑与验收指标（平台方案 A）

## 里程碑
1) 里程碑 A：平台端路由与基础页面可访问
- 平台 `/education` 与子路由全部可访问
- 教学页面嵌入在平台布局中，无跳转

2) 里程碑 B：UI/UX 统一完成
- 教学页面使用 bs-ui 组件与平台主题变量
- 视觉与智能体构建/广场风格一致

3) 里程碑 C：功能流畅与数据稳定
- 课程/章节/进度/实践/引导功能可用
- API 请求成功率与错误提示一致

4) 里程碑 D：清理遗留入口
- 客户端 `/education` 路由移除或最小化重定向
- 平台入口成为唯一访问点

## 验收指标
- 一致性：视觉与交互不出现“跳转感”或风格割裂
- 可用性：教学主流程（进入->学习->进度->实践->引导）无阻断
- 权限：无权限用户不可见教学入口或访问被拦截
- 性能：教学页面首屏加载与平台其他页面同量级
- 可维护性：教学相关路由、组件、样式集中在平台端
