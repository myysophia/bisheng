# Task 4 统一信息架构与导航结构（v1）

## 目标
- 将“智能体教学”内嵌在平台主应用中，保持一致的导航与信息层级。
- 降低用户在平台与教学之间的跳转成本，保留现有权限与路由结构。
- 为后续样式统一与内嵌容器组件提供清晰的导航与面包屑规范。

## 现状依据（关键入口）
- 平台侧边主导航：`src/frontend/platform/src/layout/MainLayout.tsx`
- 平台路由树：`src/frontend/platform/src/routes.tsx`
- 教学模块路由：`src/frontend/client/src/routes/index.tsx`

## 方案对比（主入口与二级导航）

### 方案 A：教学作为主入口
优点：符合“教学优先”的业务定位；教学用户进入路径更短。  
缺点：与当前平台默认首页 `/square` 不一致；logo 跳转与路由默认值冲突，需要更多适配。  
适用场景：平台以教学为核心 KPI，广场/构建为次级入口。

### 方案 B（推荐）：广场为主入口，教学为一级主导航
优点：与当前默认路由 `/square` 一致；现有导航结构改动最小；易与构建/模型等模块并列。  
缺点：教学入口相对多一步，需要在侧边栏与首页卡片引导。  
适用场景：平台仍是综合工作台，教学是核心功能之一但非唯一入口。

推荐理由：当前路由与侧边栏结构已以 `/square` 为默认，改动成本更低，后续整合风险更小。

### 二级导航（页头/页内）
| 顶级模块 | 二级导航形态 | 范围 |
| --- | --- | --- |

教育页内标签建议：
- 教学中心：`/education`
- 学习进度：`/education/progress`

### 面包屑规则（教育模块）
基准前缀：`智能体教学`（主导航组）  
示例：
- 教学中心：智能体教学 / 教学中心
- 课程详情：智能体教学 / 教学中心 / {课程名}
- 章节学习：智能体教学 / 教学中心 / {课程名} / {章节名}
- 学习进度：智能体教学 / 学习进度
- 实践环境：智能体教学 / 实践环境
- 引导式构建：智能体教学 / 引导式构建
- 创建成功：智能体教学 / 引导式构建 / 成功

### 面包屑规则（知识库/数据集）
由于入口归属“智能体教学”组，建议统一前缀：
- 知识库：智能体教学 / 知识库 / {子页面}
- 数据集：智能体教学 / 数据集 / {子页面}
